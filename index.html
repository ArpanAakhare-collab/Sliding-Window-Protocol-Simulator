Top Examination Questions & Model Answers

Prepared for Computer Networks Lab & Theory Examinations

1. Channel Utilization / Efficiency (η)

η = Useful Transmission Time / Total Cycle Time = Tt / (Tt + 2 • Tp)

Defining normalized delay parameter a = Tp / Tt (Propagation Delay ÷ Transmission Delay):

  • Stop-and-Wait: η = 1 / (1 + 2a)
  • Go-Back-N & Selective Repeat: η = min(1, N / (1 + 2a))

2. Delay Calculations

Tt = Frame Size L (bits) / Bandwidth B (bps)  |  Tp = Distance d (m) / Speed v (m/s)
  • Round Trip Time (RTT): RTT ≈ 2 • Tp
  • Total Transfer Time per frame: Ttotal = Tt + 2 • Tp

3. Optimal Window Size & Bandwidth-Delay Product (BDP)

Wopt = 1 + 2a = 1 + (2 • Tp / Tt)

To achieve 100% channel utilization, sender window size N must satisfy N ≥ 1 + 2a, which fully saturates the link pipeline.

4. Window Size vs Sequence Space (2m)

  • Go-Back-N: Ws ≤ 2m - 1. If Ws = 2m, receiver cannot distinguish a retransmission from a brand new cycle!
  • Selective Repeat: Ws + Wr ≤ 2m. When Ws = Wr = N, then N ≤ 2m-1.
